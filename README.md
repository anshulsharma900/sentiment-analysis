# Twitter Sentiment Analysis

A machine learning web app that classifies tweets as positive or negative.

## Live Demo
https://sentiment-analysis-slcxdbf4s74xckxc9acx9b.streamlit.app

## Tech Stack
- Python, Pandas, NLTK
- Scikit-learn, TF-IDF, Logistic Regression
- Streamlit

## Features
- Trained on 1.6 million tweets
- ~78% accuracy
- Real-time sentiment prediction
- Interactive web interface

## How to Run Locally
pip install -r requirements.txt
streamlit run app.py
